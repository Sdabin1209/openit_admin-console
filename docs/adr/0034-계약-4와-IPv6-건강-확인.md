# ADR 0034: 계약 4.0.0과 건강 확인 주소

상태: 채택 (2026-11-07).

계약 4.0.0의 검토 요청·비식별 trace·공통 타입을 고정 태그에서 재생성한다. TypeScript는 문자열의 부정 정규식 제약을 나타낼 수 없으므로 not-only allOf 가지를 타입 생성 입력에서만 제거한다. 이 투영은 문자열을 객체 교차 타입으로 잘못 만드는 생성기 동작을 막는다. 송신 전 런타임 검증에는 원본 스키마를 적용한다.

건강 확인은 ADMIN_HOST를 따르며 IPv6 authority에 괄호를 붙인다. 와일드카드 주소는 같은 주소 계열의 루프백으로 바꾼다. 서버 포트는 Caddyfile의 8080이다. 호스트별 실행 시험과 실제 이미지 healthy/unhealthy 스모크로 검증한다.
